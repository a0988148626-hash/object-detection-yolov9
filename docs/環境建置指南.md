# YOLOv9 在 Anaconda + Visual Studio Code 本機環境建置指南

這份指南把你目前在 Google Colab 上跑的 YOLOv9，改成在你自己 Windows 電腦上、用 Anaconda 管理環境、VS Code 開發執行。

你電腦上 `D:\Software` 已經有 `Anaconda3-2026.07-1-Windows-x86_64.exe`，代表你已經下載好安裝檔但可能還沒裝好，下面從安裝開始講。

---

## 0. 前置需求

| 項目 | 說明 |
|---|---|
| Anaconda | 你已有安裝檔在 `D:\Software\Anaconda3-2026.07-1-Windows-x86_64.exe`，直接雙擊執行安裝即可（一路預設值就好，記得勾選「Add Anaconda to my PATH」那個選項，雖然安裝程式預設不建議勾，但這樣後續 VS Code 抓環境會比較方便；不勾也沒關係，只是要改用「Anaconda Prompt」而不是一般 cmd） |
| VS Code | 到 https://code.visualstudio.com/ 下載安裝（若還沒裝） |
| VS Code 擴充套件 | 開啟 VS Code → 左側擴充套件圖示 → 搜尋安裝：**Python**（Microsoft）、**Pylance**（Microsoft） |
| Git | 若還沒裝，到 https://git-scm.com/download/win 下載安裝（用來下載 YOLOv9 原始碼） |
| GPU（選用） | 若你的電腦有 NVIDIA 獨立顯卡，先確認裝好最新的 NVIDIA 顯示卡驅動程式（在「NVIDIA 控制台」或裝置管理員可以看到型號）。沒有獨立顯卡也能跑，只是訓練/推論速度會慢很多，會自動改用 CPU 版本 |

---

## 1. 安裝 Anaconda

雙擊執行 `D:\Software\Anaconda3-2026.07-1-Windows-x86_64.exe`，一路 Next 安裝到底即可（安裝路徑用預設的 `C:\Users\<你的帳號>\anaconda3` 最省事）。

安裝完成後，從「開始」選單搜尋 **Anaconda Prompt** 開啟它（之後所有指令都在這個視窗裡執行，不要用一般的 cmd 或 PowerShell）。

---

## 2. 一鍵建置 YOLOv9 環境

把附件裡的 `setup_yolov9_conda.bat` 存到你想放專案的地方，例如 `C:\Users\Admin\Documents\yolov9_project\`。

在 **Anaconda Prompt** 裡：

```bat
cd C:\Users\Admin\Documents\yolov9_project
setup_yolov9_conda.bat
```

這個腳本會自動依序：

1. 建立一個叫 `yolov9` 的獨立 conda 環境（Python 3.9），跟你其他專案的環境互不干擾
2. 偵測你電腦有沒有 NVIDIA GPU（用 `nvidia-smi`），有的話裝 CUDA 版 PyTorch，沒有就裝 CPU 版
3. 用 `git clone` 下載 YOLOv9 官方原始碼（WongKinYiu/yolov9）
4. 安裝 YOLOv9 需要的所有 Python 套件（`requirements.txt`）
5. 下載兩組預訓練權重：`yolov9-c-converted.pt`（完整版）、`gelan-c.pt`（輕量版，CPU 或較舊顯卡也扛得住）

跑完之後，資料夾底下會多出一個 `yolov9\` 子資料夾，裡面就是完整的 YOLOv9 專案。

---

## 3. 在 VS Code 開啟並設定

1. 開啟 VS Code → **File > Open Folder** → 選擇剛剛產生的 `yolov9` 資料夾（例如 `C:\Users\Admin\Documents\yolov9_project\yolov9`）
2. 把附件裡的 `.vscode` 資料夾（含 `settings.json`、`launch.json`）複製貼到這個 `yolov9` 資料夾裡（跟 `detect.py`、`train.py` 同一層）
3. `Ctrl+Shift+P` 開啟命令面板 → 輸入 **Python: Select Interpreter** → 選擇路徑包含 `envs\yolov9\python.exe` 的那個（就是我們剛建立的 conda 環境）
4. 開啟 VS Code 內建終端機（**Terminal > New Terminal**），應該會自動顯示 `(yolov9)` 表示環境已啟動；如果沒有，手動輸入 `conda activate yolov9`

---

## 4. 測試推論

在 VS Code 的終端機（確認前面有 `(yolov9)`）：

```bash
python detect.py --weights weights/yolov9-c-converted.pt --conf 0.25 --img 640 --device 0 --source data/images/horses.jpg
```

- 有 GPU：`--device 0`
- 沒有 GPU（跑 CPU）：把 `--device 0` 改成 `--device cpu`

跑完後，結果圖片會存在 `runs/detect/exp/horses.jpg`，用 VS Code 或檔案總管打開確認有框出偵測結果。

也可以直接按 `F5`，用附帶的 `launch.json` 設定直接偵錯/執行 `detect.py`（可在 `launch.json` 裡改 `--source` 換成你自己的圖片路徑，例如你之前 `C:\Users\Admin\Downloads\object\object` 的貓狗人照片）。

---

## 5. 訓練自己的資料集（選用）

如果之後要拿你自己的資料集（例如 cat/Dog/persan，或標註好的其他類別）重新訓練：

1. 把圖片和 YOLO 格式標註（`.txt`，內容是 `class x_center y_center width height`，皆為 0~1 正規化值）整理成：

   ```
   yolov9/
   └── my_dataset/
       ├── images/train, images/val
       └── labels/train, labels/val
   ```

2. 在 `yolov9/data/` 底下新增 `custom.yaml`：

   ```yaml
   train: my_dataset/images/train
   val: my_dataset/images/val
   nc: 3
   names: ['cat', 'dog', 'person']
   ```

3. 用附帶 `launch.json` 裡的「YOLOv9: 訓練 train.py」設定直接按 F5 開始訓練，或在終端機執行：

   ```bash
   python train.py --workers 4 --device 0 --batch 8 --img 640 --epochs 100 --data data/custom.yaml --weights weights/gelan-c.pt --cfg models/detect/gelan-c.yaml --hyp hyp.scratch-high.yaml --name custom_train
   ```

   （先用 `gelan-c` 輕量版驗證流程沒問題，之後有需要再換成 `yolov9-c` / `yolov9-e`，但那兩個是 dual-branch 架構，要改用 `train_dual.py` / `detect_dual.py`。）

你之前整理好的 `cat/Dog/persan` 圖片目前只有分類、沒有 bounding box 標註，若要拿來訓練 YOLOv9（而不是只做推論），需要先用標註工具（例如 [LabelImg](https://github.com/HumanSignal/labelImg) 或 [Roboflow](https://roboflow.com/) 網頁工具）畫出每張圖的框並標好類別，才能產生 YOLO 格式的 `.txt` 標註檔。

## 疑難排解

| 問題 | 解法 |
|---|---|
| `setup_yolov9_conda.bat` 顯示「建立環境失敗」 | 確認是在 **Anaconda Prompt**（不是一般 cmd）裡執行 |
| VS Code 選不到 `yolov9` 環境 | 先在 Anaconda Prompt 執行 `conda env list` 確認環境存在，並確認 VS Code 有安裝 Python 擴充套件後重開 VS Code |
| 跑 `detect.py` 出現 CUDA 相關錯誤 | 通常是顯卡驅動版本跟 CUDA 版本不合，最快的解法是改用 `--device cpu` 先跑通，或重新執行 `pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118` |
| `pip install -r requirements.txt` 某個套件裝不起來 | 通常是網路暫時的問題，重跑一次 `pip install -r requirements.txt` 即可；若持續失敗，把錯誤訊息貼給我，我可以幫你看 |
