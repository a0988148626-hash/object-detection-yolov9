# 免費物件偵測／影像辨識資料來源整理

分成兩大類：**A. 即時影像串流（類似 twipcam）** 和 **B. 標註好的訓練用資料集**，物件偵測訓練通常需要 B 類（有 bounding box 標註），A 類則適合拿來做「即時推論的輸入來源」或自己收集畫面後手動標註。

---

## A. 台灣即時影像／監視器來源（類似 twipcam）

twipcam 本身其實是**政府資料開放平臺**上架的一個應用，底層串接的是公路局、水利署等單位的公開影像來源。可以直接用這些原始來源，效果跟 twipcam 一樣、且更穩定：

| 來源 | 說明 | 連結 |
|---|---|---|
| **TDX 運輸資料流通服務平臺** | 交通部官方 Open API，含國道、省道 CCTV 即時影像 URL（依縣市查詢），例如 `Road/Traffic/CCTV/City/{City}`。需免費註冊 API Key，有完整 Python/JS 範例程式碼 | [TDX 平臺](https://tdx.transportdata.tw/)、[範例程式 GitHub](https://github.com/tdxmotc/SampleCode)、[介接教學](https://hackmd.io/@hexschool/H1VfZLW4F) |
| **高速公路 1968 即時影像** | 國道公路局即時影像牆，可直接瀏覽或擷取影像 URL | [1968.freeway.gov.tw/roadcctv](https://1968.freeway.gov.tw/roadcctv) |
| **智慧化省道即時資訊服務網（公路局 168）** | 省道 CCTV 即時影像 | [168.thb.gov.tw](https://168.thb.gov.tw/) |
| **經濟部水利署水利資料開放平台** | 河川、抽水站、滯洪池等防災即時影像，有完整 Open API | [opendata.wra.gov.tw](https://opendata.wra.gov.tw/)、[OpenAPI 文件](https://opendata.wra.gov.tw/openapi)、[data.gov.tw 資料集](https://data.gov.tw/dataset/36687) |
| **水利署防災資訊網（河川便利通）** | 河川監控影像即時瀏覽 | [fhy.wra.gov.tw/fhyv2/monitor/cctv](https://fhy.wra.gov.tw/fhyv2/monitor/cctv) |
| **twipcam 原始資料集** | twipcam 本身也在政府資料開放平臺上架，可查看它實際串接的資料來源清單 | [data.gov.tw/applications/136168](https://data.gov.tw/applications/136168) |
| **tw.live / ocam.live** | 民間整理的即時影像入口，功能與 twipcam 類似，可交叉比對畫面來源 | [tw.live](https://tw.live/)、[ocam.live](https://ocam.live/) |
| **台灣公路 CCTV 清單（GitHub）** | 有人整理好的公路 CCTV 影像 URL 清單，可直接用程式批次抓取 | [gist.github.com/lyshie](https://gist.github.com/lyshie/385244be22be697f2e1ef9f123f87859) |

**用途建議**：這些是「即時影像串流」，本身沒有標註，適合：
1. 當作訓練好的模型（例如 YOLOv9/YOLOv1）的**即時推論輸入來源**（車流、行人偵測 demo）。
2. 自己定時擷取畫面，之後用 LabelImg / Roboflow 等工具手動標註，做客製化資料集。
3. TDX 的 API 需要申請免費帳號（會員中心註冊即可），額度對個人專案通常足夠。

## B. 免費標註好的物件偵測資料集

| 資料集 | 內容 | 連結 |
|---|---|---|
| **COCO (Common Objects in Context)** | 80 類日常物件，33 萬張圖片，物件偵測最常用的基準資料集 | [cocodataset.org](https://cocodataset.org)、[Roboflow 版本](https://universe.roboflow.com/microsoft/coco) |
| **Open Images V7** | Google 出品，600+ 類、900 萬張圖片，含 bounding box / segmentation / 關係標註 | [下載頁](https://storage.googleapis.com/openimages/web/download_v7.html)、[Ultralytics 文件](https://docs.ultralytics.com/datasets/detect/open-images-v7) |
| **Objects365** | 365 類、170 萬張圖片，物件數量比 COCO 多很多，適合預訓練 | [官網](https://www.objects365.org/download.html)、[Hugging Face](https://huggingface.co/datasets/jxu124/objects365) |
| **LVIS** | 長尾分布，1200+ 類細粒度標註，適合稀有類別偵測研究 | [Ultralytics 文件](https://docs.ultralytics.com/datasets/detect/lvis) |
| **PASCAL VOC 2007/2012** | 20 類資料集，適合小規模驗證 | — |
| **Roboflow Universe** | 超過 20 萬個社群上傳的公開資料集（車輛、動物、工業零件、交通號誌等各種主題），可直接匯出成 YOLO 格式 | [universe.roboflow.com](https://universe.roboflow.com/) |
| **Roboflow Public Datasets** | Roboflow 官方整理的公開資料集清單（含下載連結） | [public.roboflow.com](https://public.roboflow.com/object-detection) |

**用途建議**：如果要重新訓練或微調 YOLOv9，Roboflow Universe 通常是最快的路——很多人已經把需要的類別標註好了，可以直接匯出成 YOLO txt 格式，不用自己標註。
